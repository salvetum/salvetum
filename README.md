### 🚀 Üzerinde Çalıştığım Projeler

**[ŞifreKasam🔐](https://github.com/salvetum/SifreKasam)**
Electron + Flask tabanlı, açık kaynak masaüstü şifre yöneticisi. CSP nonce sistemi, CSRF koruması, TLS pinning gibi güvenlik sıkılaştırmaları yaptım; backend'i 14 modüle, frontend'i CSS/JS bazında onlarca dosyaya böldüm. Kendi liquid glass UI sistemim var.

**[SSC On Windows🎧](https://github.com/salvetum/SSCOnWindows)**
Samsung Seamless Codec (SSC) desteğini Windows'a taşıyan bir proje — düşük gecikmeli (~1.5ms), 24-bit/48kHz kalitede Bluetooth ses. WinUI3 + Mica tasarımlı bir arayüzü var, geliştirme aşamasında.

**[Kendin dene IDE🧑‍💻](https://github.com/salvetum/kendindeneide)**
CodeMirror tabanlı, tek sayfalık web kod editörü. TR/EN dil desteği, localStorage ile kayıt, tema seçenekleri.

**[Market Memento🤑](https://github.com/salvetum/MarketMemento)**
Steam market geçmişini steaminventoryhelper ile alabileceğiniz csv dosyası ile analiz eden local-first bir webapp.
